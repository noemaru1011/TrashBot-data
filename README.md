# TrashBot-data

LINE Trash AIで使用するゴミ出しスケジュール・分別ルールを管理するためのリポジトリです。

ゴミ出しに関する情報をYAML形式で管理し、アプリケーションからGitHub APIを通じて取得します。

## 概要

本リポジトリでは、主に以下の情報を管理します。

- **ゴミ出しスケジュール**
  - 曜日ごとのゴミ出し予定
  - 第何週などの周期指定
  - ゴミの種類
- **ゴミの分別ルール**
  - 品目ごとの分別区分
  - 品目に関する情報

データをYAML形式で管理することで、以下のメリットがあります。

- 人間が直接確認・編集しやすい
- GitHub上で変更履歴を管理できる
- アプリケーションから簡単に読み込める
- データベースを用意する必要がない

## データ構造

### 1. ゴミ出しスケジュール

`data/trash/schedule.yaml`

曜日ごとのゴミ出しスケジュールを管理します。

管理する情報の例：

- ゴミ出しを行う曜日
- 第何週かの指定
- ゴミの種類

```yaml
schedule:
  # 毎週
  - weekday: monday
    type:

  # 第1金曜日
  - weekday: friday
    week: 1
    type:
```

| 項目 | 説明 |
|---|---|
| `weekday` | ゴミ出しを行う曜日 |
| `week` | 週の指定 |
| `type` | ゴミの種類 |

### 2. ゴミの分別ルール

`data/trash/` 配下の各YAMLファイルで、品目ごとの分別ルールを管理します。

ファイルは品目名の読み仮名に応じて分類しています。

| ファイル | 分類 |
|---|---|
| `a.yaml` | あ行 |
| `ka.yaml` | か行 |
| `sa.yaml` | さ行 |
| `ta.yaml` | た行 |
| `na.yaml` | な行 |
| `ha.yaml` | は行 |
| `ma.yaml` | ま行 |
| `ya.yaml` | や行 |
| `ra.yaml` | ら行 |
| `wa.yaml` | わ行 |

各ファイルには、該当する読み仮名の品目と分別情報を登録します。

例：

```yaml
- name: アイロン
  type:
```

| 項目 | 説明 |
|---|---|
| `name` | 品目名 |
| `type` | 分別区分 |

※上記は記述イメージです。実際のYAML構造に合わせてください。

## データの更新方法

ゴミ出しスケジュールや分別ルールに変更があった場合は、対象のYAMLファイルを編集します。

### スケジュールを変更する場合

1. `data/trash/schedule.yaml` を開く
2. 該当する曜日・週・ゴミの種類を編集する
3. YAMLの構文に問題がないことを確認する
4. GitHubに変更を反映する

### 分別ルールを追加する場合

1. 品目の読み仮名に対応するYAMLファイルを開く
2. 品目と分別区分を追加する
3. YAMLの構文に問題がないことを確認する
4. GitHubに変更を反映する

## 記述ルール

データを追加・変更する際は、以下の点に注意してください。

- インデントには半角スペースを使用する
- 品目は読み仮名に応じたファイルに登録する
- 品目名の表記を統一する
- 分別区分の表記を統一する
- 同じ品目の重複登録を避ける
- YAMLとして正しい構文になっていることを確認する

## アプリケーションとの連携

本リポジトリのデータは、LINE Trash AIからGitHub APIを通じて取得されます。

アプリケーション側では、Gemini APIのFunction Callingによってユーザーの質問内容に応じたToolを実行し、本リポジトリに保存された情報を参照します。

| 利用用途 | 参照ファイル |
|---|---|
| 今日・明日のゴミ出し確認 | `schedule.yaml` |
| 指定曜日のゴミ出し確認 | `schedule.yaml` |
| 次回のゴミ出し確認 | `schedule.yaml` |
| 品目の分別方法確認 | 各行別YAMLファイル |
